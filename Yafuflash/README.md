## Yafuflash
Yafuflash is a utility used to upgrade the firmware using different mediums like LAN, USB and KCS. Latest YAFU supports Linux, Windows and DOS operating systems.
## Usage
Yafuflash [OPTION] [FW_IMAGE_FILE]
## Deliverables
**For Windows**
 - Yafuflash.exe  
 - LIBIPMI.dll  
 - Amifldrv64.sys
 
 **For Linux**
 - Yafuflash
 
 **For DOS**
 - Yafuflash.exe
 - Yafuflash.sym
